# Meta 앱 심사 준비 현황

## 현재 제공되는 것

- 한국어 브라우저 시제품과 가상 샘플 3종
- 필드별 문서 근거, 수정 근거, 검토·보류·승인 흐름
- 승인 전 RFQ 차단 및 변경 시 초안 무효화
- 발송과 분리된 RFQ 초안 미리보기

## 현재 제공되지 않는 것

- Meta 앱 ID 및 선택된 Meta 제품
- Meta 로그인·인증·접근 토큰 처리
- Meta API 호출과 권한별 실제 사용 흐름
- 사용자 계정, 서버 저장소, 서버 측 승인 검증
- 공개된 운영 서비스 주소 및 운영자 정보
- 운영 서비스의 실제 데이터 처리에 맞춘 개인정보처리방침·삭제 안내
- 심사자용 접근 방법과 실제 연동 기능의 시연 자료

## 제출 전 결정할 정보

앱 ID, 연동할 Meta 제품, 요청할 권한, 해당 권한을 사용하는 기능, 운영 URL을 먼저 확정해야 합니다. 해당 제품의 공식 심사 안내와 앱 대시보드에서 요구사항을 확인한 뒤 실제 연동과 제출 자료를 준비해야 합니다.

이 문서는 현재 코드의 준비 현황입니다. Meta의 공식 심사 체크리스트나 승인 보장이 아닙니다. 미구현 기능을 구현 완료로 기재하지 마세요.
