# QuoteSync Meta Step 0

도면에서 추출한 품목 정보를 사람이 검토·수정·승인한 뒤 RFQ 초안을 만드는 한국어 시제품입니다. 기존 QuoteSync 프로젝트와 독립된 프로젝트입니다.

## 실행

`index.html`을 브라우저에서 여세요. 설치, API 키, 서버가 필요 없습니다.

## 시연

1. A 정상 / B 누락·무처리 / C 상충 샘플을 선택하고 불러옵니다.
2. 각 항목의 근거와 상태를 확인합니다.
3. 누락·판독불가·상충 항목은 값, 수정자, 이유, 근거를 입력해 수정합니다.
4. 각 필드를 승인합니다. 보류 또는 미해결 항목이 있으면 RFQ가 차단됩니다.
5. RFQ 초안을 생성합니다. 수정·보류·변경 재분석 시 기존 초안이 무효화됩니다.

## 구현 범위

- 합성 샘플만 사용하며 문서 업로드·OCR·AI 분석은 구현하지 않았습니다.
- 실제 API 호출, Meta 로그인, Meta API 연동, RFQ 발송이 없습니다.
- 작업 상태는 브라우저 localStorage에 저장됩니다. 작업 초기화 버튼으로 삭제할 수 있습니다. 저장 실패 시 화면에 안내합니다.
- 승인 및 검증은 브라우저 내부 시연이며 사용자 인증·서버 검증이 없습니다.
- 비용 계산기의 단가는 원본 샘플의 고정 예시이며 현재 서비스 요금이나 청구 확인을 뜻하지 않습니다.

Meta 앱 심사 준비 상태와 미구현 항목은 [제출 준비 문서](docs/meta-review.md)를 참고하세요. GitHub 저장소 생성은 Meta 앱 등록 또는 심사 제출을 대신하지 않습니다.

## 검증

Node.js 22 이상에서 외부 패키지 설치 없이 실행합니다.

```sh
node --test
```

## 배포

일반 정적 파일 호스팅이 가능합니다. GitHub Pages를 사용할 경우 저장소 설정에서 배포 브랜치 `main`, 폴더 `/ (root)`를 지정할 수 있습니다. 이 프로젝트는 자동 배포를 활성화하지 않습니다.

## 데이터

시제품은 입력 내용을 서버에 전송하지 않으며 현재 브라우저에 저장합니다. 실제 개인정보·고객 도면 대신 샘플 데이터로 시연하세요. 라이선스는 아직 지정하지 않았습니다.
